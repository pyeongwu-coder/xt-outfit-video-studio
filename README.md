# xt-outfit-video-studio

穿搭换装视频工作室：把模特参考、服装图片和视觉风格组合成可播放的穿搭短视频。

这是我一直在用的一套穿搭视频 Skill，现在把它公开出来。它适合想用 AI 做穿搭展示、换装视频、Lookbook 和参考视频复刻的人，也适合希望直接拿自己的模特图、服装图开始创作的人。

## 它能做什么

- **多种穿搭视频风格**：内置复古像素换装、工位卡点变装、真实穿搭卡点、巨人之手真人换装、韩系三色点缀配色等风格，也支持上传参考视频自定义拆解。
- **爆款形式复刻**：可以分析参考视频中的镜头结构、动作机制、节奏和转场，再替换成自己的模特与服装素材；只迁移可观察的制作逻辑，不复制原视频人物、商标、受保护角色或完整文案。
- **从素材到成片**：工作目标是生成可播放的视频，不止输出提示词或分析报告。Skill 会按选定风格组织提示词、调用媒体能力，并在生成后检查人物稳定性、服装匹配、镜头节奏和画面瑕疵。
- **指定图片作为硬参考**：支持上传真人/数字人形象、服装参考图和自定义风格参考。服装的版型、主色、图案、材质观感和关键配件以用户提供的图片为准，无法确认的细节不会擅自补写。
- **更安全的生成边界**：真人图片只作为本次身份参考；不识别真实身份、不推断敏感属性，也不继承参考图中的原服装。生成结果会明确标记已确认、暂定、缺失和冲突的信息。

## 安装

### 方式一：使用 Skills CLI

如果你的 Agent 支持 [Agent Skills](https://agentskills.io/) 规范，可以尝试：

```bash
npx skills add pyeongwu-coder/xt-outfit-video-studio
```

如果 CLI 没有自动识别根目录 Skill，也可以使用下面的克隆方式。

### 方式二：克隆后复制到 Agent 的 skills 目录

```bash
git clone https://github.com/pyeongwu-coder/xt-outfit-video-studio.git
```

然后把仓库目录放入你的 Agent 的 skills 目录，并确保入口文件位于：

```text
xt-outfit-video-studio/
└── SKILL.md
```

不同 Agent 的安装目录可能不同，请以对应 Agent 的文档为准。

## 使用前准备

这个 Skill 的远程图片/视频理解、素材上传和媒体生成依赖 `ai-tool-center` MCP。使用前请在 Agent 中完成 MCP 配置，并确认工具列表中出现对应能力；不要把真实 API Key 写入仓库、日志或提示词。

生成视频前，至少准备：

1. 一个已确认的视频风格；
2. 一张真人参考图，或一份数字人角色描述；
3. 至少一张服装参考图；
4. 需要保留的身份、服装、场景、文案或声音要求。

不确定选哪种风格时，直接对 Agent 说：

```text
请使用 xt-outfit-video-studio，先让我选择穿搭视频风格。
```

选定风格后，再补充模特图、服装图和输出规格。Skill 不会在风格未确认时先生成模特、关键帧或视频。

## 重要说明

- 生成视频前必须先确认一个风格。
- 服装参考图是硬参考，不承诺模型能够百分之百还原每个细节。
- 参考视频只负责镜头、动作、节奏和转场；模特图负责身份，服装图负责服装。
- 如果当前 Agent 没有可用的 `ai-tool-center` MCP，Skill 会停在配置提醒，不会伪造生成结果或偷偷改用其他外部服务。
- 本仓库当前为公开发布版本，尚未附加具体开源许可证；如需允许他人明确修改、再分发或商用，建议后续补充许可证文件。
