# 提示词与成片验收

## 母版结构硬规则

命中的 `风格/*.md` 是最终视频提示词的结构和细节密度母版。它不是只供提炼风格关键词的灵感文本。先在内部建立“母版段落 → 本次段落”映射，再开始写最终提示词；除非用户明确要求精简提示词，否则不得把多个母版段落合并成一句概述。

最终提示词应保留母版中适用于当前任务的层级与顺序：

1. 风格、时长、画幅、清晰度或摄影质感；
2. 参考图片/视频的编号、职责和禁止继承项；
3. 人物角色卡、身份锁定、允许变化与禁止变化；
4. 固定场景、光线、机位、焦段、景别和运镜规则；
5. 覆盖完整时长的连续时间轴；
6. 表演连续性、换装机制、声音、真实质感和负面约束。

每个时间轴段落必须写成可拍摄、可执行的动作说明，至少交代：

- 镜头开始时的景别、人物站位、朝向、当前穿着和道具状态；
- 巨手、鼠标、衣物、卡片或其他触发物从哪个画面方向进入，以什么姿态接近目标；
- 动作如何开始、经过哪些中间步骤、衣物怎样与身体或道具发生物理接触；
- 换装前后分别改变什么、保持什么，硬切或转场发生在哪个明确动作点；
- 人物的手臂、头部、视线、重心、表情和服装布料如何响应；
- 镜头结束时的完整造型、构图、定格姿势，以及与下一段如何衔接；
- 该段对应的音乐强拍、环境声或操作音效；没有音频需求时明确无对白、无随机声音。

风格特有机制必须按母版展开。例如“巨人之手”不能只写“巨手递入服装并完成硬切”，而要写清手的数量、大小、入画方向、手指如何拿取服装、接触人物的部位、衣物的移动路径、人物的机械配合与最终穿着状态。像素换装要展开 UI、卡片、鼠标移动、点击反馈和装备结果；工位卡点要展开切点前后的同一动作惯性；全身 Lookbook 要展开鼓点、身体对齐和每套定格；韩系三色点缀配色要展开每组的双色基础状态、第三色触发手势、切后新增单品，以及色点和标签在同一切点的同步变化。

若用户素材比母版多，应新增同等密度的时间段；若素材更少，应删除无素材段落并重新分配时长，不得用一句话塞入多套造型。若运行时提示词长度受限，优先删去修饰词和重复形容词，不得删掉参考职责、动作因果、换装前后状态、服装硬特征、连续性和安全约束。

## 提示词编排

完整视频提示词按以下顺序组织，使用自然语言和时间轴，不要只堆风格词：

1. **规格**：时长、画幅、分辨率、帧率观感、真实或像素化程度。
2. **参考职责**：`I1` 模特身份、`G1...Gn` 服装、参考视频风格职责。
3. **全局锁定**：同一人物、身体比例、场景、机位、光线和不可变化项。
4. **时间轴**：每段起止时间、景别、动作、换装触发、目标服装、转场和声音卡点。
5. **最终造型清单**：逐件列出必须出现的服装和配饰。
6. **负面约束**：身份漂移、服装错误、肢体与穿模、暴露风险、镜头和背景跳动、文字与水印问题。

预设文件提供风格骨架，下面字段必须替换：

- 示例人物名和 `@` → 本次角色代称与 `I1`；
- 示例服装 → `G1...Gn` 的可见细节；
- 示例换装次数 → 用户真实造型数量；
- 示例文案、标签和配音 → 用户确认内容；
- 用户未锁定的场景可沿用预设，已指定场景则以用户为准。

## 提交前提示词验收

提交生成任务前逐项检查：

- 时间码从 `00:00` 连续覆盖到目标时长，无无意空档、重叠或越界；
- 每个母版镜头都有明确的保留、替换、扩展或删除去向；
- 每套 `G1...Gn` 都有穿戴过程、完整上身结果和至少一个清晰展示节点；
- 每个换装节点均描述“触发前状态 → 触发动作 → 切换点 → 触发后状态”，没有无因换装；
- 每个段落均达到母版的动作与画面细节密度，不存在“巨手完成换装”“人物展示造型”一类无法直接执行的概括句；
- 参考职责、身份锁定、服装硬特征、场景连续性、声音和负面约束均已写入最终提交文本，而不是只存在于生成清单或思考中。

任一项不通过，先补写提示词再调用视频生成工具。

## 服装连续性规则

- 每次换装写清“变化项”和“保持项”。例如只换上衣时，裤装、鞋、人物位置和动作必须明确保持。
- 硬切前后写出动作匹配点，例如“旧造型手指开始按键，新造型完成同一次按键”。
- 不允许渐变生长、融化、皮肤变衣服、烟雾遮盖或无因换装，除非所选风格明确要求该机制。
- 物理穿戴风格必须使用安全不透明基础层；衣物与身体正确接触，不穿透手臂、头发或配件。

## 成片验收

### P0：任一失败则必须返工或明确未通过

- 视频能够播放，时长和画幅符合任务；
- 全程同一人物，无换脸、年龄漂移、明显身材漂移或多余人物；
- 无裸体、走光、性化未成年人、肢体畸变或危险强迫场面；
- 用户指定的核心服装至少在计划镜头中出现，且没有被完全替换成另一件；
- 无无关品牌、错误商标、乱码大字或平台水印。

### P1：风格和服装质量

- 每个造型的主色、版型、领口/袖型/裤型、显著图案和关键配件与参考一致；
- 换装顺序和卡点数量正确，没有提前出现、残留叠穿或漏件；
- 所选风格的核心机制成立：像素点击装备、工位动作匹配、全身重拍硬切、或巨手逐件穿戴；
- 韩系三色点缀配色中，每组的服装颜色、色点顺序和标签语义一致；当三种源颜色不同，三个色点不得错误显示成同色；
- 人物站位、背景、机位和光线在需要锁定的镜头中稳定；
- 文字、标签、声音和动作同步；未要求文字时没有随机字幕。

### P2：发布可用性

- 关键服装无遮挡，头部和鞋子在全身风格中完整入画；
- 无明显塑料皮肤、布料漂浮、包带/眼镜/鞋袜穿模或背景家具跳动；
- 结尾有足够的最终造型停留，便于用户看清穿搭。

## 结果状态

交付时使用：

- `已确认`：从用户素材、已选风格或真实工具结果中验证。
- `暂定`：创意补全或模型生成但未获用户确认。
- `缺失`：没有足够素材判断或生成。
- `冲突`：用户要求、风格规则或参考素材之间不一致，必须指出具体冲突。

不要把“任务提交成功”当成“成片验收通过”。
